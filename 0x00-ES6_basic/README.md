## Introduction

ES6 (ECMAScript 2015) introduced significant improvements to JavaScript, enhancing readability, maintainability, and functionality. This project focuses on implementing ES6 features such as:

- `const` and `let` keywords  
- Block scoping  
- Arrow functions  
- Default function parameters  
- Rest and spread syntax  
- Template literals  
- Object property shorthand  
- Computed property names  
- Iterators and `for-of` loops
